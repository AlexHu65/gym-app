# Infraestructura local

Este directorio agrupa la base operativa del entorno de desarrollo.

Contenido actual:

- `docker-compose.yml` en la raiz del monorepo
- servicios locales para PostgreSQL, Redis, MinIO y Mailpit

Siguientes pasos recomendados:

- mover o duplicar la composicion local aqui si el equipo prefiere separar infraestructura
- agregar variables de entorno por ambiente
- agregar scripts de arranque y validacion
