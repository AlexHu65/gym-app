# Client PWA

App orientada al usuario final con Angular + Ionic.

## Objetivo

- explorar el catalogo de ejercicios
- ver detalle con media e instrucciones
- guardar favoritos
- crear rutinas simples
- registrar sesiones de entrenamiento

## Entrada

- `src/main.ts`

## Rutas base

- `/`
- `/exercises`
- `/exercises/:id`
- `/favorites`
- `/workouts`
- `/login`
